# Watermelon

**Difficulty:** `Easy`

## Problem

Pete and his friend Billy have a watermelon. It weighs w kilograms. They want to divide it into two parts. Each part must weigh an even number of kilograms. Each part must also weigh more than zero kilograms.

Note: The two parts do not need to weigh the same amount. Each part's weight must be a positive even number. The two parts together must weigh exactly w kilograms.

Read w from standard input. Print "YES" if such a division exists. Print "NO" if it does not exist.

## Examples

### Example 1

**Input**
```
w = 8
```
**Output**
```
YES
```

**Explanation:** 8 can be split into 2 and 6, or into 4 and 4. Both parts are positive and even.

### Example 2

**Input**
```
w = 3
```
**Output**
```
NO
```

**Explanation:** 3 is odd, so it can never be written as a sum of two even numbers.
