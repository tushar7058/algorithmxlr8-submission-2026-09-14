# Domino Piling

**Difficulty:** `Easy`

## Problem

You are given a board with n rows and m columns. Find the maximum number of 1 by 2 dominoes that can be placed on the board so that each domino covers exactly two neighboring cells, dominoes do not overlap, and no domino sticks out past the edge of the board.

Read two integers n and m from standard input, on one line. Print one integer, the maximum number of dominoes.

## Examples

### Example 1

**Input**
```
n = 2, m = 4
```
**Output**
```
4
```

**Explanation:** The 8 cell board can be completely covered, 4 dominoes fit.

### Example 2

**Input**
```
n = 3, m = 3
```
**Output**
```
4
```

**Explanation:** The 9 cell board has one cell always left over, so at most 4 dominoes fit.
